## About these records

Each directory snapshot links to the exact README reviewed and records its review
date and license metadata. A separate comparison baseline appears when that analysis
used another revision. [Source inventory (JSON)](sources.json) is the machine-readable record.

This index includes reviewed discovery candidates as well as admitted entries.
An appearance here is evidence of inspection, not a recommendation or independent
validation of upstream code. [Curation policy](CURATION.md) · [Choice notes](CHOICES.md).
